# 李颖｜运营作品集 V2

第二版独立运营主站。内容沿用运营作品集的信息架构，视觉和滚动体验借鉴 LENIS：全屏标题、固定导航、滚动进度、Sticky 能力区、案例筛选和沉浸式背景。

## 本地运行

```powershell
npm install
npm run dev
```

## 内容边界

- AI 生图 Agent 单独标记为正式实习经历，未写入未经确认的业务增长数字。
- 个人账号数据统一采用简历口径：200 万累计播放、3 万获赞、40 万单条最高播放、300+ 视频、80+ 图文；校园活动的 230 位观众仅归入活动案例。
- Haivis 运营两个月新增注册用户统一为 2100+。
- AI 网站、小程序和动画没有作为本版运营主案例，只作为可迁移能力和 AI 赋能运营证据。
